# ntfy-native

A lightweight native macOS menu bar client for ntfy. Subscribe to a topic, receive macOS notifications, and publish messages. The interface follows your system language and supports Simplified Chinese, English, French, German, and Spanish.

一个轻量、原生的 macOS 菜单栏 ntfy 客户端，可订阅 topic、接收 macOS 通知并发布消息。界面默认跟随系统语言，支持简体中文、英文、法文、德文和西班牙文。
