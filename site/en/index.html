02 / CONNECT THE DOTS.

At the other end of a command,
there’s your Mac.

Give your existing automations another way to reach you.
No dedicated SDK required in your scripts.

  1. 01

    Configure subscriptions and Notes

    Open Settings from the menu bar, choose an ntfy server, add one or more subscriptions, and optionally set a Note for each. Add a token if authentication is required.

  2. 02

    Save the connection and allow notifications

    Save and connect. Allow notifications when macOS asks. The app will then wait for messages in your menu bar.

  3. 03

    Send a message from any script

    Publish with an ntfy HTTP POST, or send a message from the app’s Settings. In-app publishing uses the first configured topic.

03 / KNOW WHERE IT GOES.

Connecting is simple.
Know the boundaries.

Your messages pass through the ntfy server you choose.
This is not “fully offline” or “messages never leave your computer.”

Messages and settings

The server address, subscription topics, and Notes are stored in local preferences; the token is stored in Keychain. The panel keeps the latest 50 messages in memory. They are not persisted as local history after you quit.

Transport and display

The server processes messages, and its configuration determines how they are stored. Messages appear in macOS notifications; lock-screen previews depend on your system notification settings.

This website

No analytics scripts, ads, or forms. The demo runs only in your browser and sends no real notifications. The website host may keep standard access logs.

04 / A FEW GOOD QUESTIONS.

Questions,
answered plainly.

Which Macs are supported?+

The current v0.1.0 build supports Apple silicon (M-series) Macs running macOS 13 or later. There are no Intel, Windows, or Linux builds at this time.

How do I install it? Why might macOS block it?+

Unzip the download, move ntfy-native-0.1.0.app to Applications, then open it. This version is ad-hoc signed and has not been signed and notarized with an Apple Developer ID, so macOS may block the first launch. Verify the download source, then follow the prompt in System Settings → Privacy & Security. Do not disable system protections to install it.

Must it stay open? Can it subscribe to multiple topics?+

The app must be running and connected to receive messages. Real-time delivery is not guaranteed while your Mac sleeps. The current public source supports multiple topics on the same server and an optional Note for each subscription; the main panel uses the Note instead of showing topic names. The downloadable v0.1.0 app predates this feature and supports one topic; build the public main branch to use multiple subscriptions. The menu bar panel shows the latest 50 messages; it is not a full notification archive.

Can it launch at login?+

Settings includes a launch-at-login switch using macOS SMAppService. Local registration, unregistration, and state persistence have been verified, but launch after logging out or restarting has not yet been tested end to end.

Is this an official ntfy client? Is the source public?+

No. This is an independently developed macOS client and is not affiliated with the ntfy project. The application source is public on GitHub under the MIT License. The downloadable v0.1.0 app is an earlier, single-topic build.

What are the known limitations?+

This is an early release. The GitHub v0.1.0 app does not yet include multiple subscriptions or Notes; those features are available in the public source. Some local notification scenarios previously showed a generic gray system icon; the fix still needs confirmation. Other macOS versions have not all been tested. Liquid Glass uses native materials on macOS 26 and later, with a native-material fallback on older systems.

Something went wrong — how do I report it?+

Please open a GitHub issue first — include your macOS version and steps to reproduce. You can also email tim@timhuang.net.
